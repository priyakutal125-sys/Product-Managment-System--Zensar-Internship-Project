##### Project Name :-  **Product Management System**







###### The Product Management System is a Java-based application used to manage product information such as product id, name, price, and quantity. This project allows the user to add new products, find a product by id, view all products, update product price, and delete products using a simple menu-driven program. It is designed to make product handling easy and organized.

###### 

###### In this project, Core Java concepts like classes, objects, methods, constructors, and packages are used. Object-Oriented Programming (OOP) concepts such as encapsulation, abstraction, inheritance, and polymorphism are applied to create a well-structured application. An interface is used to define product operations, and the DAO (Data Access Object) pattern is followed to separate database logic from business logic.

###### 

###### The project uses JDBC (Java Database Connectivity) to connect the Java application with a MySQL database, where all product data is stored permanently. A utility class is used to create and manage the database connection. Exception handling is implemented to handle errors properly, including a custom exception for situations when data is not found. Overall, this project helps in understanding how real-world Java applications work with databases using clean and simple design.
